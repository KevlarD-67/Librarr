## Roadmap delta

- **Now → Done:** effectively all of it. Phases 0 through 12 landed
  inside this window and shipped as `v1.0.0-beta` — the native
  OpenLibrary metadata source (`OpenLibraryProxy`), the `BookIdMapping`
  bridge table, `ReidentifyService`, first-boot legacy migration for
  existing Readarr libraries, edition-language mapping, the narrator
  schema, and the move from Azure Pipelines to GitHub Actions. Full
  detail in [`CHANGELOG.md`](../../CHANGELOG.md) under `[1.0.0-beta]`.
- **Soon → Now:** nothing. The Soon bucket emptied into Done in the
  same burst rather than advancing a stage at a time.
- **Later → Soon:** nothing.
- **New entries:** the buckets themselves. `roadmap.md`,
  `governance.md` and `deferred-modernization.md` were all created
  2026-05-17, `release-checklist.md`, `ol-bulk-data.md` and this
  directory's README on 2026-05-18 — every one of them inside the same
  four-day burst that shipped the beta. So the honest delta for Q2 is
  not that items moved between buckets; it is that the buckets, the
  release gates and the governance model were written at the same time
  as the code they describe, and then none of them were touched again
  before the quarter ended.

## Retro: what didn't ship

**All 98 commits landed in four days.** 2026-05-16 through 05-19, then
42 days of silence to the end of the quarter. The 1.0.0-beta tag went
out on day four and the next commit of any kind was 2026-07-23, well
into Q3. This is the single most useful fact about the quarter: the
project does not move at a steady rate, it moves in multi-day bursts
separated by weeks of nothing. Planning that assumes a weekly cadence
will be wrong in both directions.

**The bus factor did not improve.** It started at one and ended at one.
Under [`governance.md`](../governance.md) that puts the 90-day
recruitment deadline at **2026-08-14**.

**The beta's own checklist stayed open.** Steps 3–5 of the manual
operator walkthrough in
[`release-checklist.md`](../release-checklist.md) — add an author end
to end, confirm narrator chips render, follow a chip to its page —
still have no verification against a real seeded library.

**The docs drifted from the code, quietly.** Several release-checklist
boxes stayed unticked for weeks after the work behind them had landed,
and `deferred-modernization.md` described a React 17 app and a .NET 8
target long after neither was true. Nothing broke as a result, which
is exactly why it went unnoticed; a checklist that is wrong in the
optimistic direction is a nuisance, but one that is wrong in the
pessimistic direction makes finished work look outstanding and invites
redoing it. Reconciled 2026-08-02.

## Asks

**A second maintainer, before 2026-08-14.** This is the one ask that
has a date attached. The alternative on that date is a maintenance-mode
declaration — security patches only, no feature work — which is a
worse outcome for a project that has a working beta and people
downloading it. Anyone interested in merge rights should open a
GitHub Discussion or an issue.

Smaller, genuinely self-contained pieces of work, useful whether or not
they lead anywhere:

- **Test on real 32-bit ARM.** `linux/arm/v7` has only ever been
  exercised under emulation, where QEMU's own Thumb translator
  asserted. That is an emulator defect rather than an application one,
  which means real hardware remains the only way to get a verdict.
- **Run the operator walkthrough** on a seeded library and report what
  breaks — steps 3–5 above.
- **Cross-browser Playwright.** The suite is Chromium-only; Firefox
  and WebKit launchers are close to one-liners.
- **A larger reidentify regression seed.** The current 10-book
  in-memory seed asserts the confidence threshold; a few hundred books
  would make the assertion mean something.
