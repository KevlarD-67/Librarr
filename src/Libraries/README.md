# Libraries/ — vendored binary

A single committed binary that the .NET ecosystem doesn't ship a NuGet
equivalent for.

## Contents

- `Interop.NetFwTypeLib.dll` — interop assembly for the Windows Firewall COM
  API (`HNetCfg.FwPolicy2`). Used by `../NzbDrone.Windows/` to add a
  firewall exception for the Readarr port at first run.

## Why vendored?

The only way to call the Windows Firewall COM API from managed code is via
an interop assembly generated by `tlbimp`. There is no first-party NuGet
package for `NetFwTypeLib`, so the generated DLL is committed here.

## Supply-chain note

This is the only opaque binary in the repo. Provenance check:

1. Open the DLL in a decompiler — types should be in the
   `NetFwTypeLib` namespace.
2. Strong name signing is irrelevant; this is interop metadata only.

See [`../../ARCHITECTURE.md`](../../ARCHITECTURE.md) §8.6 for the SBOM
caveat this introduces.
